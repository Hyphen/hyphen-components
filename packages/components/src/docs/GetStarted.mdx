# Get Started

### 1. Install

`pnpm add @hyphen/hyphen-components`

or

`npm install @hyphen/hyphen-components`

### 2. Import Global CSS

```jsx
import '@hyphen/hyphen-components/dist/css/utilities.css';
import '@hyphen/hyphen-components/dist/css/variables.css';
import '@hyphen/hyphen-components/dist/css/index.css';
```

### 3. Import Global CSS Reset (Optional)

```jsx
import '@hyphen/hyphen-components/dist/css/reset.css';
```

### 4. Import Font (Optional)

```jsx
import '@hyphen/hyphen-components/dist/css/fonts';
```

### 5. Basic Usage

```jsx
import React from 'react';
import ReactDOM from 'react-dom';
import { Box } from '@hyphen/hyphen-components';

function App() {
  return <Box>Hello World</Box>;
}

ReactDOM.render(<App />, document.querySelector('#app'));
```

### 6. Compose with the right element

Use `as` or `asChild` when a Hyphen component needs to render with different
HTML semantics or reuse a router link or trigger. See
[Polymorphic Composition](?path=/docs/about-polymorphic-composition--docs) for
the supported patterns and accessibility guidance.
